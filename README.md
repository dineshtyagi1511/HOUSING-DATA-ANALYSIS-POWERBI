# HOUSING-DATA-ANALYSIS-POWERBI


In this project, we work with housing market data powered by Google Cloud Platform’s BigQuery,  through a complete end-to-end reporting workflow—from SQL-based data cleaning to advanced DAX-driven analysis, all the way to publishing your report in Power BI Service.



**🏘 Project:** Housing Data Analysis

**Data Source:** Google BigQuery

**Dataset:** Housing Market Data

**Tools Used:** Power BI Desktop, Power BI Service, SQL in BigQuery, Power Query Editor

## 📊 Report Structure – 3 Pages of Insightful Visuals:

**📄 Page 1:**  Housing Market Overview
Year-over-Year (YoY) Sales Growth by Category
Median Sales Price Changes by Region
Total Units Sold
Offer Price vs Sales Price Analysis

**📄 Page 2:**  Sales Performance by Region
Sales Volume by Region
Average Selling Price per Region
Offer Price per Square Meter Comparison

**📄 Page 3:** Deep-Dive by House Type
Offer vs Purchase Price
Average Inflation vs Yield
Square Meter Price Trends

## 🧹 Data Cleaning & Prep:

Use SQL in BigQuery to clean and prep data

Apply Power Query transformations to shape your data for reporting

## 💡 DAX Functions in Focus:
Build your DAX confidence with formulas like:

 CALCULATE, YEAR, MAX, IF, BLANK, MEDIANX, DISTINCTCOUNT, QUARTER, DATESINPERIOD, ALLEXCEPT, TOTALYTD, and more.

## 🌐 Online Report Management:
Create a dedicated workspace in Power BI Service
Publish and manage your report online for seamless access and sharing
